## Goal

On a Linux host or a Raspberry Pi: run the container with `--device /dev/snd` (the tool adds it for an audio service, F11) and a real output, check which device the keywords pick inside the container, whether the image needs an ALSA configuration or the `audio` group, and build and run on arm64.

## Why postponed

Decision of the maintainer of 2026-11-09: the Raspberry Pi, arm64 and native Linux wait until the services work at 100 % on Windows. It is not "next". What can be done without the Pi: a `pip install --dry-run --only-binary=:all: --platform manylinux_2_28_aarch64 --python-version 3.12` of the pins of T-01.5 (inside T-01.5).
