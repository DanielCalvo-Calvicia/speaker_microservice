## Goal

Prove the image has no dev tools and no unused packages (R-5) and no secret; the `.env` is only mounted. Same method as stt [T-03.4](../../../../stt_microservice/docs/tasks/T-03_docker-and-arm64-acceptance/T-03.4_image-contents-and-secrets.md): searches are for the **absence** of a name; print counts, never a value.

## Steps

1. `pip list` inside the image: no `pytest`, `httpx`, `ruff`, `black`, `mypy`, `numpy`, `soundfile`, `websockets`.
2. `ls -la /app`: no `.env`, `windows`, `.git`.
3. `docker history --no-trunc` and `docker inspect` of the image and the running container: no key-like variable (counts only); the `.env` is a read-only bind mount.
4. `docker save <image> | tar -t`: no `.env` entry.
5. The user of the process: record it (the image has no `USER`, so root; a finding for `docs/security/security.md`).

## Acceptance criteria

Steps 1 to 4 find nothing unexpected; the user is recorded.

## Result (2026-11-10)

All by counts and names. **Packages:** `pip list` in the image has no `pytest`, `httpx`, `ruff`, `black`, `mypy`, `numpy`, `soundfile` or `websockets` (20 packages with pip: fastapi, uvicorn, python-dotenv, sounddevice, starlette, pydantic, contracts-microservice, shared-logging and their dependencies). **Files:** `ls -A /app` of the image has no `.env`, `.env.staging`, `.env.production`, `windows`, `.git`, `.venv` or `testclear`; it does hold `tests/` and `docs/` (the Dockerfile copies the whole tree). **Secrets:** 0 matches for `API_KEY`, `SECRET`, `TOKEN`, `PASSWORD`, `sk-` and `gsk_` in `docker history --no-trunc`, in `docker inspect` of the image and of the running container; the container's environment is only the Python base image's variables (`GPG_KEY` is that image's public key id); the one mount is `/app/.env`, read-only. **Layers:** 8,428 file entries in `docker save`, **0** `.env*` entries other than `.env.example`. **User:** `Config.User` is empty: root (a finding for `docs/security/security.md`, not fixed here).
