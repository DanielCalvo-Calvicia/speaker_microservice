## Goal

On a Linux machine with several ALSA outputs, find out whether the default keywords `i2s,hw,default,sysdefault` pick the wrong device (R-3, F13) and what the per-machine setting should be (`SPEAKER_DEVICE_INDEX` or `SPEAKER_DEVICE_KEYWORDS` in `deployment/config/local/speaker.toml`; the keywords are already per machine, there is no separate hardware config).

## Steps

List the devices the kernel sees (`aplay -l`) next to what the service chose (its log); try the index and the keywords; record. No change to the code default without a result.

On Windows nothing is needed (F13). Not "next": do not offer it as a follow-up until the postponement is lifted.
